### Command line tool

`run.py` is a command line tool to test functions in this repository quickly.  
For example:

```bash
python run.py -m {module_name} -f {function_name} -i {input_arguments}

# input_arguments are a list of arguments without any space, use \ for string quotes
# For eg., -i [\'geeks\',\'nerd\'] or -i [1,2] or -i [[1,2,3],[2,3]]
